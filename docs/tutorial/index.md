# Tutorial

This section of our documentation contains a hands-on tutorial to help you learn how to set up your environment, deploy Charmed Etcd, and access a database.

## Prerequisites
While this tutorial intends to guide you as you deploy Charmed Etcd for the first time, it will be most beneficial if:

* You have some experience using a Linux-based CLI
* Your computer fulfils the [minimum system requirements](#system-requirements)
