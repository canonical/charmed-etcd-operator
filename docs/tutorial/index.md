# Tutorial

This hands-on tutorial teaches you how to set up your environment, deploy Charmed Etcd, and access a database.

## Prerequisites
You'll get the most out of this tutorial if:

* You have some experience using a Linux-based CLI
* You have a basic understanding of the [Juju orchestration engine](https://documentation.ubuntu.com/juju/latest/)
* Your computer fulfils the [minimum system requirements](#system-requirements)
