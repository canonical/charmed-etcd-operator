# Charmed Etcd documentation

Etcd is a distributed, reliable key-value store for the most critical data of distributed systems. This charmed operator deploys and operates etcd on virtual machines.

Charmed Etd is equipped with several features to securely store and scale complicated data workloads, including TLS encryption, horizontal scaling, password rotation, and easy integration with client applications.
