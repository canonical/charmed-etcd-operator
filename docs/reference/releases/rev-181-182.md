# Revisions 181, 182

A new version of Charmed etcd has been published in the `3.6/stable` channel.

```{eval-rst}
+---------------+--------------+----------------+---------------+
| Architectue   | Etcd Version | Charm Revision | Snap Revision |
+===============+==============+================+===============+
| AMD           | 3.6.13       | 181            | 38            |
+---------------+              +----------------+---------------+
| ARM           |              | 182            | 37            |
+---------------+--------------+----------------+---------------+
```

## Highlights

* Update etcd to version 3.6.13
* new configuration options for `auto-compaction` [#244](https://github.com/canonical/charmed-etcd-operator/pull/244)
* Support for full key space access by clients [#208](https://github.com/canonical/charmed-etcd-operator/pull/208)

### Bugfixes and Improvements

* Support bulk event handling in client relations [#182](https://github.com/canonical/charmed-etcd-operator/pull/182)
* Fix: allow same TLS provider as client application [#190](https://github.com/canonical/charmed-etcd-operator/pull/190)
* Fix mTLS in cross-model relations [#236](https://github.com/canonical/charmed-etcd-operator/pull/236)
* Security and stability improvements [#239](https://github.com/canonical/charmed-etcd-operator/pull/239)

### Requirements and compatibility

* Juju v3.6.11+ 
  * Older minor versions of Juju 3 may be compatible, but are not officially supported. 
* LXD v6.4+
  * Older LXD versions may be compatible, but are not officially supported. 
* Integration with a TLS provider charm
  * `tls-certificates` interface v4
