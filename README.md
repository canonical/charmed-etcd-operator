## Charmed etcd operator
[![CharmHub Badge](https://charmhub.io/charmed-etcd/badge.svg)](https://charmhub.io/charmed-etcd)

The Charmed etcd Operator deploys and operates the [etcd](https://etcd.io) 
software on VMs and machine clusters. This charm is a 
Python project that installs etcd from the [etcd Snap](https://snapcraft.io/charmed-etcd),
and provides lifecycle management and event handling.

## Documentation

The documentation for this charm is not yet published to a public domain. 

To build the docs locally, navigate to the `/docs` folder in this repository and run the following command:
```
make run
```
You will then be able to see it in your browser at http://127.0.0.1:8000
